# Бюджет — PWA

Личное приложение для учёта доходов, расходов и сбережений. Устанавливается на телефон и ПК как обычное приложение.

- **Интерфейс** — этот репозиторий (GitHub Pages): `index.html`, `manifest.webmanifest`, `sw.js`.
- **Сервер** — Google Apps Script (JSON-API, вход по паролю).
- **База данных** — Google Таблица «Бюджет — данные».
- **Операции из банка** — SMS и пуши Сбербанка через MacroDroid → отдельный скрипт-приёмник → лист «Входящие».

Адрес сервера в коде не хранится. Его передают один раз ссылкой вида
`https://evgeniyakovlevv-ship-it.github.io/budget-app/#api=<адрес Apps Script>`, после чего он запоминается на устройстве.

## Обновление
После изменения файлов увеличьте `CACHE` в `sw.js` (например, `budget-v2`), чтобы телефоны подхватили новую версию.
